# Е-Монтаж — Заміри: як запустити і викласти в магазини

## Що в архіві

| Файл | Навіщо |
|---|---|
| `index.html` | Сам додаток: вхід, бланк, архів, адмін-панель |
| `privacy.html` | Політика конфіденційності (обов'язкова для Play Market і App Store) |
| `manifest.webmanifest`, `sw.js` | Щоб додаток встановлювався як програма і відкривався без інтернету |
| `icon-*.png`, `apple-touch-icon.png` | Іконки |
| `firestore.rules` | Правила безпеки бази — копіюються у Firebase |

## Логотип

Адміністратор (ви) завжди бачить логотип Е-Монтаж. Кожна інша компанія завантажує свій у **Профіль → Логотип**; він показується вгорі програми і на бланку для друку. Поки логотипу немає — замість нього назва компанії. Екран входу завжди з логотипом Е-Монтаж.

## Мови

Українська, English, Polski, Русский, Español. Мову обирають на екрані входу (🌐 угорі) або в **Профіль → Мова**; вона діє на форму, друк, Share і лист для відновлення пароля. Спершу програма бере мову телефона. Вибір запам'ятовується на пристрої.

Бланки зберігаються незалежно від мови: бланк, заповнений польською, відкриється українською з тими самими даними. Політика конфіденційності поки лише українською — для публікації в інших країнах її варто перекласти.

## Ролі

- **Безкоштовно** — кожен новий акаунт, 14 днів. Потім програма блокується, бланки зберігаються.
- **Клієнт** — платний доступ без обмежень. Ставить адміністратор.
- **Адміністратор** — ви. Бачите всі компанії, змінюєте ролі, продовжуєте пробний період (+14 дн.).

Кожна компанія бачить тільки свої бланки. Змінити собі роль користувач не може — це перевіряє сама база.

## Крок 1. Перед публікацією заповніть

1. `index.html` → знайдіть рядок `var SUPPORT_CONTACT` і впишіть свій телефон. Його бачить клієнт, коли закінчився пробний період.
2. `privacy.html` → замініть усі місця, виділені жовтим: `[ПІБ або назва ФОП / компанії]` і `[email]`.

## Крок 2. Firebase (один раз, 10 хвилин)

Відкрийте console.firebase.google.com → проєкт **app-zamir**.

1. **Authentication** → Get started → Sign-in method → **Email/Password** → Enable → Save.
2. **Authentication** → Settings → Authorized domains → Add domain → `onazarthuk-app.github.io`.
3. **Authentication** → Templates → (олівець) → Template language → **Ukrainian** — тоді лист для відновлення пароля прийде українською.
4. **Firestore Database** → Rules → видаліть усе, вставте вміст `firestore.rules` → **Publish**.

## Крок 3. Викласти на GitHub Pages

1. github.com → New repository → назва `zamir` → Public → Create.
2. Add file → Upload files → перетягніть **усі файли з архіву** → Commit.
3. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 хвилини додаток буде за адресою `https://onazarthuk-app.github.io/zamir/`.

## Крок 4. Зробити себе адміністратором

1. Відкрийте додаток → Реєстрація → зареєструйтесь своїм email.
2. Firebase → Firestore Database → колекція `users` → ваш документ (email збігається) → поле `role` → змініть `free` на `admin` → Update.
3. Оновіть сторінку. У Профілі з'явиться **Адмін-панель**.
4. У Профілі впишіть своїх менеджерів (по одному в рядку).

## Крок 5. Файл для Play Market

Зібрати файл можна безкоштовно на pwabuilder.com — він сам упаковує сайт у програму для Android.

1. Відкрийте **pwabuilder.com** → вставте `https://onazarthuk-app.github.io/zamir/` → Start.
2. **Package for stores** → **Android** → Generate Package.
   - Package ID: `ua.emontazh.zamir` (потім змінити не можна)
   - App name: `Е-Монтаж — Заміри`, Short name: `Заміри`
   - Signing key: **Create new**
3. Download. В архіві будуть:
   - `.aab` — **цей файл завантажується в Play Market**;
   - `.apk` — для перевірки на своєму телефоні;
   - `signing.keystore` і `signing-key-info.txt` — **ключ підпису. Збережіть у трьох місцях. Без нього ви ніколи не зможете оновити додаток у магазині.**
   - `assetlinks.json` — див. наступний пункт.
4. **assetlinks.json** — без нього зверху в додатку буде видно адресний рядок браузера:
   - створіть на GitHub ще один репозиторій з назвою рівно `onazarthuk-app.github.io` (якщо його ще немає);
   - покладіть у нього порожній файл `.nojekyll` і файл `.well-known/assetlinks.json` (у полі назви файла наберіть `.well-known/assetlinks.json` — GitHub сам створить папку);
   - Settings → Pages → `main` → Save;
   - перевірка: `https://onazarthuk-app.github.io/.well-known/assetlinks.json` має відкриватися.
5. Встановіть `.apk` на свій Android і перевірте вхід, збереження, друк.

## Крок 6. Google Play Console

1. play.google.com/console → акаунт розробника, **$25 один раз**. Потрібна верифікація особи.
2. Create app → мова українська → App, Free.
3. Обов'язково заповнити:
   - **Privacy policy:** `https://onazarthuk-app.github.io/zamir/privacy.html`
   - **Data safety:** збираються email, ім'я / телефон / адреса (дані замовників), фото; шифрування при передачі — так; користувач може видалити дані — так; посилання на видалення: `https://onazarthuk-app.github.io/zamir/privacy.html#delete`
   - **App access:** дайте тестовий логін і пароль з роллю Клієнт (рецензент Google має увійти).
   - Target audience: 18+, Ads: немає, Content rating — анкета.
   - Скріншоти телефона (мінімум 2), іконка 512×512 (`icon-512.png`), банер 1024×500.
4. **Важливо для нових особистих акаунтів:** перед публікацією Google вимагає **закрите тестування — 12 тестувальників протягом 14 днів**. Додайте email колег/монтажників у Closed testing, завантажте `.aab`, і через 14 днів подавайте на Production.

## Крок 7. App Store (iPhone)

- Потрібні: **Mac з Xcode** і **Apple Developer — $99 на рік**.
- PWABuilder → Package for stores → **iOS** → завантажте проєкт → відкрийте в Xcode → Archive → завантажте в App Store Connect.
- Ризик: Apple часто відхиляє програми, які є «сайтом в обгортці» (правило 4.2). Шанси кращі, якщо в описі й скріншотах видно повноцінні функції: підпис, фото, друк, архів, робота без інтернету.
- Без App Store на iPhone можна вже зараз: Safari → адреса додатку → Поділитися → **На початковий екран**.

## Оплата

У програмі немає кнопок оплати: клієнт домовляється з вами напряму, а ви ставите йому роль «Клієнт» в адмін-панелі. Для бізнес-інструментів, де доступ купується поза програмою, магазини це зазвичай дозволяють, але **не пишіть у програмі ціни і посилання на оплату** — інакше Google і Apple вимагатимуть свою платіжну систему (15–30% комісії). Перед публікацією перечитайте актуальні правила Google Play Payments і App Store 3.1.

## Що зберігається де

- Чернетка поточного бланка — на пристрої.
- Кнопка **Хмара** — бланк, фото і підпис у Firebase. Повторне натискання оновлює той самий бланк.
- **Профіль → Архів бланків** — усі збережені бланки, пошук, відкрити, видалити.
- **Профіль → Новий бланк** — очистити форму.
- Безкоштовного тарифу Firebase (Spark) вистачає приблизно на кілька тисяч бланків з фото. Коли база підійде до 1 ГБ, Firebase попередить.
